KernelProject2

root:~# a kernel that runs Linux programs as they are

KernelProject2 is a kernel written from scratch in Rust. It answers Linux's system calls the way Linux does, so you can take a program out of Ubuntu, copy it in, and run it. How it works

More screenshots

New this week: it boots straight into Vela, the desktop, now after Windows Vista: glass, KDE's Oxygen icons, photo wallpapers and a Personalize window. There's a boot splash (any key shows the [  OK  ] lines), a Welcome window, an installer that puts the system on a disk, and it runs on more than one CPU. See it

An installer, and more than one CPU

October 13, 2026

install puts KernelProject2 on a hard disk so it starts without the ISO: a GPT partition table, a FAT32 boot partition with the kernel, and an ext2 home that becomes /root. All three are written by our own code, and the test checks the result with Linux's own tools before booting it with UEFI firmware.

The kernel also starts every CPU now. Four busy programs on four CPUs finish in about the time one takes alone. The kernel itself still runs on one CPU at a time, under one lock, which is how Linux started out too.
