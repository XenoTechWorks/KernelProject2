KernelProject2

root:~# a kernel that runs Linux programs as they are

Download

There are no prebuilt images yet, so you build it from source. It runs in QEMU.

What you need

Linux, or WSL on Windows. On Ubuntu 24.04:

sudo apt install qemu-system-x86 xorriso cpio gcc g++ gcc-mingw-w64-x86-64
rustup toolchain install nightly --component rust-src --target x86_64-unknown-none
git clone --depth=1 --branch=v11.2.1-binary https://codeberg.org/Limine/Limine.git ~/tools/limine
make -C ~/tools/limine

You also need Zig 0.17, unpacked in ~/tools/zig-x86_64-linux-0.17.0 (or point ZIG= at it).

Build and run

git clone https://github.com/XenoTechWorks/KernelProject2
cd KernelProject2
./build.sh
./run.sh

build.sh builds the kernel and the tools and copies in the Linux programs it finds on your machine, along with their libraries. Two programs are big, so they're optional:

WITH_PYTHON=1 ./build.sh   # Python and its standard library
WITH_GDB=1 ./build.sh      # gdb

./run.sh starts it with 4 CPUs (CPUS=2 ./run.sh for fewer), ./run.sh --text without a window or the desktop, and ./run.sh --installed disk.img boots a disk you installed onto.

Once it's running

You get Vela, the desktop, with a Welcome window to start from. The Terminal in the dock is the shell: try help, ls /bin or fastfetch. To put the system on a disk, use Install in the star menu. Your files in /root are kept on a disk image between boots.

Running the tests

python3 tests/smoke.py

The other tests are next to it in tests/.
